# Схема БД до перехода на миграции

Файлы в этой папке описывают схему БД **по версию 0.26.0 включительно** и
больше не пополняются. Начиная с 0.27.0 все изменения схемы оформляются
миграциями — см. [docs/db-migrations.md](../../../docs/db-migrations.md).

- `dump.sql` — дамп схемы на версии 0.26.0.
- `changes-log.sql` — история изменений схемы от первых версий до 0.26.0.

## Когда это нужно

**Новая установка** — эти файлы не нужны: схему целиком создаёт первая
миграция, `php lpm-cli/migrate.php apply` на пустой базе.

**Установка версии 0.26.0 или новее** — тоже не нужны: при первом запуске
миграций схема принимается за исходную, ничего не выполняется.

**Установка старее 0.26.0** — накатите из `changes-log.sql` блоки от своей
версии до `-- 0.26.0` включительно, и только потом запускайте миграции: они
рассчитывают, что схема соответствует 0.26.0.

## Почему файлы оставлены

`changes-log.sql` — единственная запись о том, как схема менялась до перехода
на миграции, включая разовые скрипты заполнения данных. `dump.sql` — точка
отсчёта, из которой получена первая миграция
(`lpm-core/modules/db/migrations/00000000000000_initial_schema.sql`).
